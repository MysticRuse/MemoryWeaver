# Moderator Agent Skill Instructions

This skill governs the safety and visual quality checks for photos uploaded to the album.

## Operations
1. **Safety Compliance**:
   - Check photos for violent, explicit, or offensive contents.
2. **Quality Screening**:
   - Filter out excessively blurry, out-of-focus, completely dark, or corrupted images.
3. **Type Verification**:
   - Discard memes, document scans, screenshots, or receipts. Only retain actual travel/trip photographs.
